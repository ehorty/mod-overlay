Оверлей для OBS и панель модератора

Ссылка для OBS находится в панели: вкладка «Админ» → «Ссылка для OBS».

OBS → Источники → «Браузер» → вставьте ссылку. Ширина 1920, высота 1080. Включите «Обновлять браузер, когда сцена становится активной».

Где работает сервер

Если порт занят, приложение подберёт следующий свободный и обновит ссылку для OBS.

Панель откроется по адресу /panel/. Ссылку для OBS возьмите во вкладке «Админ» в панели.
